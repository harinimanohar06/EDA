# 🛍️ Retail Store Data Analysis

## 📌 Project Overview
This project analyzes retail store data to uncover insights about customer behavior, product performance, and sales trends.

Using Python and data analysis libraries, the dataset was cleaned, explored, and visualized to generate meaningful business insights.

The analysis includes multiple datasets such as customers, products, stores, sales transactions, and exchange rates.

---

## 🎯 Project Objectives

- Perform data cleaning and preprocessing
- Conduct exploratory data analysis (EDA)
- Identify sales patterns and trends
- Analyze customer demographics
- Evaluate product category performance
- Create visualizations for business insights

---

## 📂 Dataset Files

| Dataset | Description |
|--------|-------------|
| Customers.csv | Customer demographic information |
| Products.csv | Product details including categories |
| Stores.csv | Store location and size information |
| Sales.csv | Transaction-level sales data |
| Exchange_Rates.csv | Currency exchange rates |
| Data_Dictionary.csv | Description of dataset columns |

---

## ⚙️ Tools & Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
